# 有限表による PEG の有界認識

`lean/Shallot/Peg/Packrat/` は、停止性を仮定しない任意の PEG について、
固定した入力での成功・失敗・導出なしを有限回の表計算で区別する。
これは保留中の `PEL ⊊ P` の形式化に向けた意味論と有限反復の部分であり、
真部分性の証明や TM 上の実行時間の証明はまだ含まない。

## 表と意味論

各セルは式と入力位置の組で、値は次の三種類。

| 値 | 意味 |
|---|---|
| `none` | まだ値がない。反復が安定した後は、導出が存在しない |
| `some none` | 意味論上の失敗 |
| `some (some k)` | `k` 文字を消費して成功 |

`F` は前の表を参照して一段を計算する。空の表からの反復を `iter` とする。
`iter_eq_run` は、各反復が同じ深さの燃料付きインタプリタ `pegRun` の結果から
構文木を除去したものと一致することを示す。これにより、既存の `Derives` に対する
健全性・完全性を再利用する。成功後の位置が入力の範囲内にあることも証明する。

## 有限回での安定

`dom g` は開始呼出しと全規則の部分式のリスト。入力末尾を含めた全位置との組を
`cells g x` とすると、その長さは `(dom g).length * (x.length + 1)`。
リストに同じ式が重複していてもよい。

一度埋まったセルの値は変わらない (`iter_mono`)。
関連セル全体で連続する二つの表が一致すれば、その後も一致する (`agree_step`,
`agree_later`)。関連セルは依存先について閉じており、成功した消費量は入力を
越えないため、範囲外のセルを使う必要がない。

安定していない各反復では少なくとも一つセルが新しく埋まる。
埋まったセル数は `cells` の長さを越えないので、
`bound g x = (dom g).length * (x.length + 1) + 1` までに安定する
(`bound_stationary`, `bound_fixed`)。

`bounded_iff` はこの時点の値と導出の存在の同値、`bounded_none_iff` は空セルと
導出の不存在の同値。開始規則では `parse_iff` / `parse_none_iff` に特殊化する。
`accepts_iff` は入力の残りを許す Ford の受理条件 `Shallot.Accepts` との一致。
文法全体の全入力での停止性を判定する定理ではない。

## 保存する実装

関数としての `iter` は仕様であり、参照のたびに再計算が起こり得る。
その反復回数だけから実行時間は結論できない。

`Stored.lean` は関連セルの値を連想リストへ保存する。`stored` の各反復は、
直前の保存済み表を `fetch` で参照し、次の表を `save` で作る。
`stored_eq_iter` で仕様との一致を証明し、`storedParse_iff` と
`storedParse_none_iff` で具体的な有限表実装を元の意味論へ接続する。

残る作業は、この保存済み表計算を計算量ライブラリの具体的な機械に載せ、
文法ごとの定数と入力長の一様な次数で実行時間を評価し、時間階層による
分離へ接続すること。現時点では `PEL ⊊ P` は未証明。

## 検証

`Examples.lean` は左再帰、空文字の反復、先行枝の発散で後続枝へ進めない選択、
先行枝の成功で発散する後続枝を呼ばない選択、規則欠落、文字不一致、
リテラルの部分消費、貪欲な反復をカーネルで検証する。
左再帰と空文字反復に関しては導出の不存在も定理へ接続している。
主要な定理の標準的依存のみを `lean/Audit.lean` のメッセージ検査で固定する。
